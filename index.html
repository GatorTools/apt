Dépôt APT de GatorTools

Les logiciels GatorTools pour Debian et Ubuntu, installés et mis à jour avec le reste du système.

Ajouter le dépôt

sudo install -d /etc/apt/keyrings
wget -qO- https://gatortools.github.io/apt/gatortools.gpg | sudo tee /etc/apt/keyrings/gatortools.gpg > /dev/null
echo "deb [signed-by=/etc/apt/keyrings/gatortools.gpg] https://gatortools.github.io/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/gatortools.list
sudo apt update

Installer CloneGator

sudo apt install clonegator

Les mises à jour arrivent ensuite avec sudo apt upgrade.

Clé de signature

Le dépôt est signé par la clé « GatorTools APT », d'empreinte 3989 0A8C E7A8 FF4B B870 7C7D 7365 5D5A 2C79 54A6. Elle est publiée ici en deux formats : gatortools.gpg (binaire, pour signed-by) et gatortools.asc (texte).
